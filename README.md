# VacationManager — Мениджър на отпуски

Уеб приложение за управление на отпуски, проекти, екипи и роли в организация (учебен проект по ASP.NET Core MVC + EF Core + SQLite).

## Стартиране

С .NET 10 SDK можете да стартирате приложението от корена на хранилището.

```bash
dotnet run --project src/VacationManager
```

Отворете `http://localhost:5295`. При първо стартиране приложението създава локалната SQLite база в папката на проекта, прилага миграциите и зарежда началните данни.

За компилация от корена използвайте `dotnet build`. Изходният код е в [src/VacationManager](src/VacationManager/).

| Потребител | Парола | Роля | Екип |
|---|---|---|---|
| `admin` | `Admin123!` | CEO | – |
| `lead` | `Lead123!` | Team Lead | Development (лидер) |
| `dev` | `Dev123!` | Developer | Development |

## Функционалност

- **Вход в системата** – cookie аутентикация, паролите се пазят хеширани (BCrypt).
- **Потребители** – CRUD само за CEO; изглед със странициране (10/25/50 на страница) и филтриране по потребителско име, собствено име, фамилия, роля; детайлен изглед, откъдето се задава екипът.
- **Роли** – CRUD само за CEO; изглед с ролите и броя потребители; детайлен изглед с потребителите от ролята. Не може да се изтрие роля с назначени потребители.
- **Екипи** – CRUD само за CEO; филтриране по име на екип/проект; детайлен изглед с разработчиците, лидера и опции да добавиш/премахнеш член и да зададеш лидер.
- **Проекти** – CRUD само за CEO; филтриране по име и описание; детайлен изглед с екипите по проекта + добавяне/премахване на екип.
- **Отпуски** – заявки за платен, неплатен и болничен отпуск (дата от/до, дата на създаване, половин ден, одобрена, заявител). Болничният изисква прикачен файл и няма половин ден. Собственикът може да редактира/трие заявката си само докато не е одобрена; сваляне на прикачения файл.
- **Одобрения** – заявка одобрява само CEO или лидерът на екипа на заявителя; лидерът не одобрява собствената си заявка (че и ако е в отпуск, CEO може – в тази версия CEO е fallback за всички).
- **Валидация** – всички форми са валидирани (задължителни полета, дължини, дати: „до“ ≥ „от“ и т.н.).

## Технологии

- ASP.NET Core MVC (.NET 10)
- Entity Framework Core 9 + SQLite ([миграции](src/VacationManager/Migrations/))
- BCrypt.Net-Next за хеширане на пароли
- Cookie authentication + ролеви филтър (`RequireRolesAttribute`)
