# ADR-001: Уеб рамка – ASP.NET Core MVC (.NET 10, C#)

Статус: Прието · 22.10.2026 · автор: Пейчев · преглед: целият екип

## Контекст
VacationManager е за организация, в която служителите подават заявки за отпуск, а лидерите на екипи и CEO ги одобряват от различни компютри и от телефон (NFR-01). В екипа има и Windows, и macOS машини (NFR-07). И тримата сме писали ASP.NET MVC проекти с EF Core в училище. Имаме 3 спринта с капацитет около 19 точки и нямаме време за учене на нова рамка.

## Решение
ASP.NET Core MVC върху .NET 10 (LTS), изгледи с Razor и Bootstrap 5. Един уеб проект (`VacationManager.csproj`), разделен по папки: `Controllers`, `Models`, `Views`, `Data`, `Middleware`, `Attributes`. Всеки модул (потребители, роли, екипи, проекти, отпуски) е отделен контролер.

## Последици
(+) един език и един проект; бърз старт с `dotnet new mvc`
(+) вградени cookie аутентикация, валидация с атрибути (NFR-04), качване на файлове и dependency injection
(+) работи еднакво под Windows и macOS; .NET 10 е LTS с поддръжка до ноември 2028
(−) страниците се рендират на сървъра – за мобилно приложение ще трябва отделен API слой
(−) всеки компютър се нуждае от .NET 10 SDK; по-старите SDK (8, 9) не компилират `net10.0`

## Алтернативи
ASP.NET Core Razor Pages (4,10), React + ASP.NET Core Web API (3,55), Java Spring Boot + Thymeleaf (3,05) – виж [матрицата](../01-избор-на-технологии.md#2-матрица-на-решенията--уеб-рамка). WinForms/WPF и MAUI отпаднаха, защото не са уеб.
